☁️ Conectar Supabase
1. Crea el proyecto en Supabase
  1. Entra a supabase.com → New project
  2. Copia Project URL y la anon public key (Settings → API)
2. Crea las tablas
  1. SQL Editor → pega el script supabase_schema.sql → Run
3. Crea usuarios y entra
  1. Authentication → Users → Add user (correo + contraseña) para cada persona autorizada
  2. Desactiva "Allow new users to sign up" para que nadie se registre solo
  3. Abre el sistema, inicia sesión con tu correo → los datos se cargan automáticamente
Vercel: al desplegar, define las variables de entorno NEXT_PUBLIC_SUPABASE_URL y NEXT_PUBLIC_SUPABASE_ANON_KEY, o crea un config.js con window.SUPA_CFG={url:'...',key:'...'}. El anon key es público por diseño; la seguridad real son el login y las políticas RLS (solo usuarios autenticados leen/escriben).
